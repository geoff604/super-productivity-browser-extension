Copy the token from Super Productivity: Settings → Misc → Access Token. It is stored only in this browser profile's local extension storage.

Firefox has not granted this extension access to 127.0.0.1, so it cannot reach the local REST API.

If access is off, enable "Access your data for http://127.0.0.1" in about:addons -> this extension -> Permissions and data.
